# الأرض الطيبة لتنسيق الحدائق

موقع متكامل لشركة تنسيق الحدائق مع لوحة تحكم إدارية.

## المتطلبات

- PHP 7.4 أو أحدث
- MySQL 5.7 أو أحدث (أو MariaDB)
- خادم Apache مع mod_rewrite
- استضافة InfinityFree (موصى بها)

## التثبيت

1. قم بإنشاء قاعدة بيانات من لوحة تحكم الاستضافة
2. استورد ملف `database.sql` إلى قاعدة البيانات
3. عدّل ملف `config.php` بمعلومات قاعدة البيانات
4. ارفع جميع الملفات إلى مجلد `htdocs` في الاستضافة
5. ادخل إلى `/admin/login.php` وقم بتسجيل الدخول
6. **مهم:** غيّر كلمة المرور الافتراضية فوراً

## بيانات الدخول الافتراضية

- **اسم المستخدم:** admin
- **كلمة المرور:** Admin@123456
